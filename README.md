# C++ 30-Day Game-Focused Learning Plan

This repository contains a 30-day learning plan for C++ focused on 2D game development (with secondary paths to systems and embedded). It includes daily tasks (plan/day-01.md … plan/day-30.md), a Day 01 example project using SFML, an MIT license, CI workflow, and helper files.

Highlights
- C++ standard: C++20
- Example library: SFML (examples/day01 uses SFML)
- Branch: feature/init-30-day-plan (this commit)

How to use
1. Clone the repo and checkout the feature branch or main after merge:
   ```bash
   git clone https://github.com/CaptionLittleBird/-cpp-30-day-plan.git
   git checkout feature/init-30-day-plan
   ```

2. Read the daily plan files in /plan to see the tasks for each day.

3. Build and run Day 01 example (requires SFML). See examples/day01/README.md for build steps.

Contributing
- This plan is designed for a beginner who knows Python and wants to learn C++ for games. Feel free to open issues or PRs to improve tasks, examples or add more examples.
